# خدمات — نموذج الصفحة الرئيسية لـ «كيف الضيافة» (v5.1)

مستودع مستقل يحمل **النسخة التامة v5** من نموذج الصفحة الرئيسية لموقع keifaldiafa.com، للمراجعة والمقارنة.
المستودع الأم (السجل الكامل، التقارير، القرارات): `MoTechSys/allpro` → `prototype-home/`.

## المحتوى
| ملف | الوصف |
|---|---|
| `index.html` | v5.1 — ملف واحد (HTML + CSS + JS)، RTL، `noindex` |
| `hero-samples.html` | عيّنات الهيرو بأربعة خطوط (`?f=a|b|c|d`) — المالك اختار **ج** |
| `img/` | الصور المصغّرة (WebP) + الشعارات + الشارات |
| `video/` | فيديو الهيرو (غير مستخدم في v5) |

## v5.1 باختصار
- الخطوط: Amiri + Noto Naskh Arabic + Marcellus.
- هيرو متوسّط بهيكلة الموقع الأصلي، بطاقة زجاجية شفافة، زرّان صف واحد، «+500» → الأعمال.
- هيدر نحيف 64px + قائمة جانبية RTL على الجوال؛ لا شريط لاصق؛ عائم واتساب وحده.
- «لمن نخدم» 3 بطاقات · «أعمالنا» شريط أفقي + معرض · الطاقم شريط · التقديمات 8 · الخدمات · «شركاء النجاح» بطاقات كريمية موحّدة · المدن · الأسئلة · تواصل · تذييل مطابق للأصل.
- الطول: 6640px @390 · 7010px @1440 · 0 أخطاء console.
